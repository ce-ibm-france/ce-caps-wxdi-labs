# IBM watsonx.data Integration — Hands-On Labs

This repository contains instructor-led lab materials for **IBM watsonx.data Integration** workshops delivered to IBM clients and partners.

Each subfolder is a self-contained lab with its own participant guide, tutor setup instructions, and supporting assets.

---

## Available Labs

| Lab | Title | Level | Duration |
|-----|-------|-------|----------|
| [`StreamSets/`](StreamSets/README.md) | Real-Time FX Rate Analytics with IBM watsonx.data Integration StreamSets | Intermediate | 3–4 hrs |

```

    └── module2/               ← Participant: import & visualise
```

## Who Is This For?

| Role | Start here |
|------|------------|
| **Lab participants** | Open the lab subfolder linked in the table above and follow the `README.md` |
| **Tutors / instructors** | Read the lab `README.md`, then work through the `setup/` guide before the session starts |
| **Content contributors** | See the contributing section below |

---

## Contributing

1. Fork the repository and create a feature branch.
2. Each new lab lives in its own top-level subfolder (e.g. `DataStage/`, `Data Replication/`).
3. Every lab subfolder must contain:
   - A `README.md` that follows the same structure as the StreamSets lab.
   - A `setup/` folder with tutor instructions.
   - At least one `module*/` folder with participant instructions.
4. Submit a pull request against `main` with a short description of the lab.
